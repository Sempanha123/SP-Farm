PHASE GOAL
----------
Create legitimate onboarding for existing/manually created authorized accounts.

MUST BUILD
----------
- Create account record.
- Create environment profile.
- Choose runtime device/app.
- Prepare environment.
- Open Facebook Lite or Official app.
- Guide user through legitimate sign-in.
- Detect/confirm success.
- Store permitted secure session/app-state ref if enabled.
- Sync allowed metadata.
- Optional prepare Official Facebook after Lite onboarding.
- Release device.

UX / UI REQUIREMENTS
--------------------
Stepper: Account → Environment → Device → App → Sign in → Verify → Link → Done.

TECHNICAL RULES
---------------
- No automated bulk signup.
- No disposable SMS account creation.
- No CAPTCHA/checkpoint bypass.

GLOBAL SAFETY / SECURITY RULES
------------------------------
- Operate only on accounts/Pages/Groups/devices/content the operator owns or is authorized to manage.
- Do not build bulk Facebook signup.
- Do not build disposable-number Facebook registration.
- Do not build CAPTCHA/checkpoint/security bypass.
- Do not build anti-detect hardware identity rotation.
- Do not generate fake IMEI/MEID/GSF/serial/advertising-ID fingerprints for Facebook evasion.
- Do not build mass-like/comment/story-view/friend-request/unsolicited-message workflows.
- Prefer official Meta APIs where supported.
- Never store secrets in source code/plaintext JSON.
- Never log secrets.

ACCEPTANCE CRITERIA

- [ ] Manual review state works.
