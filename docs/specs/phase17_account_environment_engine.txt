PHASE GOAL
----------
Create the persistent environment planner/apply/restore lifecycle.

MUST BUILD
----------
- EnvironmentPlanner.
- Compatibility checks.
- Environment revisions.
- Prepare device.
- Apply environment.
- Restore permitted encrypted app/session state.
- Health check.
- Optional safe backup.
- Cleanup/release.
- Persist runtime history.

UX / UI REQUIREMENTS
--------------------
Account → Environment tab shows revision/status/app/network/last runtime/restore/backup.

TECHNICAL RULES
---------------
- One account may run on different compatible devices.
- Runtime host reusable after cleanup.
- No fake fingerprint generation.

GLOBAL SAFETY / SECURITY RULES
------------------------------
- Operate only on accounts/Pages/Groups/devices/content the operator owns or is authorized to manage.
- Do not build bulk Facebook signup.
- Do not build disposable-number Facebook registration.
- Do not build CAPTCHA/checkpoint/security bypass.
- Do not build anti-detect hardware identity rotation.
- Do not generate fake IMEI/MEID/GSF/serial/advertising-ID fingerprints for Facebook evasion.
- Do not build mass-like/comment/story-view/friend-request/unsolicited-message workflows.
- Prefer official Meta APIs where supported.
- Never store secrets in source code/plaintext JSON.
- Never log secrets.

ACCEPTANCE CRITERIA

- [ ] Compatibility failures explicit.
- [ ] History recorded.
