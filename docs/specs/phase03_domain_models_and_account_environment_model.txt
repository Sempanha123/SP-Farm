PHASE GOAL
----------
Define business entities, including the corrected separation between account environment and runtime device.

MUST BUILD
----------
- Create Account, AccountEmail, AccountPhone, AccountSecurity, Page, Group.
- Create AccountEnvironmentProfile and EnvironmentRevision.
- Create RuntimeDevice, RuntimeHistoryRecord, DeviceAssignment/Lease.
- Create AppPackage, ContentAsset, Campaign, Schedule, Job, JobAttempt, ProviderAccount, NetworkProfile, LocationProfile, AuditEvent.
- Create enums and validated state transitions.
- Use UUID internal IDs.

UX / UI REQUIREMENTS
--------------------
No production UI required.

TECHNICAL RULES
---------------
- Do not store raw secrets in entities.
- Do not include fake device fingerprint generation.
- Runtime device and account environment are distinct.

GLOBAL SAFETY / SECURITY RULES
------------------------------
- Operate only on accounts/Pages/Groups/devices/content the operator owns or is authorized to manage.
- Do not build bulk Facebook signup.
- Do not build disposable-number Facebook registration.
- Do not build CAPTCHA/checkpoint/security bypass.
- Do not build anti-detect hardware identity rotation.
- Do not generate fake IMEI/MEID/GSF/serial/advertising-ID fingerprints for Facebook evasion.
- Do not build mass-like/comment/story-view/friend-request/unsolicited-message workflows.
- Prefer official Meta APIs where supported.
- Never store secrets in source code/plaintext JSON.
- Never log secrets.

ACCEPTANCE CRITERIA

- [ ] Environment profile can move between compatible runtime devices.
