PHASE GOAL
----------
Create the architecture skeleton before any real feature work.

MUST BUILD
----------
- Create presentation/application/domain/infrastructure/workers/shared packages.
- Create dependency container/bootstrap.
- Create Command, Query, Event, Result and AppError foundations.
- Create in-process event bus.
- Create UnitOfWork interface.
- Create architecture dependency tests.
- Write docs/architecture.md.

UX / UI REQUIREMENTS
--------------------
Developer-only architecture status screen is enough.

TECHNICAL RULES
---------------
- Domain imports no UI/SQL/network/device libraries.
- Presentation only calls application commands/queries.
- Infrastructure implements interfaces.

GLOBAL SAFETY / SECURITY RULES
------------------------------
- Operate only on accounts/Pages/Groups/devices/content the operator owns or is authorized to manage.
- Do not build bulk Facebook signup.
- Do not build disposable-number Facebook registration.
- Do not build CAPTCHA/checkpoint/security bypass.
- Do not build anti-detect hardware identity rotation.
- Do not generate fake IMEI/MEID/GSF/serial/advertising-ID fingerprints for Facebook evasion.
- Do not build mass-like/comment/story-view/friend-request/unsolicited-message workflows.
- Prefer official Meta APIs where supported.
- Never store secrets in source code/plaintext JSON.
- Never log secrets.
