PHASE GOAL

MUST BUILD
----------
- 2FA state.
- Guided TOTP setup.
- Recovery contacts.
- Primary email/phone.
- Owned contact change flow.

- Last security review.

UX / UI REQUIREMENTS
--------------------
Checklist/status dashboard.

TECHNICAL RULES
---------------
- TOTP secret only in SecretStore.
- High-risk changes confirmed/audited.
- No security bypass.

GLOBAL SAFETY / SECURITY RULES
------------------------------
- Operate only on accounts/Pages/Groups/devices/content the operator owns or is authorized to manage.
- Do not build bulk Facebook signup.
- Do not build disposable-number Facebook registration.
- Do not build CAPTCHA/checkpoint/security bypass.
- Do not build anti-detect hardware identity rotation.
- Do not generate fake IMEI/MEID/GSF/serial/advertising-ID fingerprints for Facebook evasion.
- Do not build mass-like/comment/story-view/friend-request/unsolicited-message workflows.
- Prefer official Meta APIs where supported.
- Never store secrets in source code/plaintext JSON.
- Never log secrets.
